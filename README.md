Реалізовано консольний запуск програми з аргументами:

ENCRYPT <filePath> <key>
DECRYPT <filePath> <key>
BRUTE_FORCE <filePath>

Реалізовано шифрування та дешифрування файлів за допомогою шифру Цезаря.
Підтримується циклічний зсув алфавіту .
Реалізовано brute-force режим, який перебирає всі можливі ключі.
Результуючі файли створюються в тій самій папці, з суфіксами [ENCRYPTED], [DECRYPTED], [BRUTE_FORCE].
Проєкт зібраний у JAR та розміщений у GitHub Releases.
